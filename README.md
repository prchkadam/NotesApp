# 📝 NotesApp

A clean and modern Notes Application built using **React.js** and **Tailwind CSS**.
This project allows users to create and view notes dynamically using React state management and component-based architecture.

Built as part of my React.js learning journey to understand:
* component communication
* props
* state management
* form handling
* dynamic rendering
* modern UI structuring

---

# 🚀 Features

* Add notes dynamically
* Real-time note rendering
* Responsive UI design
* Component-based architecture
* React state management using `useState`
* Props-based data flow
* Modern Tailwind CSS styling
* Reusable React components

# ⚙️ Installation & Setup

## 1. Clone the repository

```bash id="jlwmu7"
git clone https://github.com/prchkadam/NotesApp.git
```

---

## 2. Navigate into the project folder

```bash id="5jlwmu"
cd NotesApp
```

---

## 3. Install dependencies

```bash id="rjlwm1"
npm install
```

---

## 4. Start development server

```bash id="qjlwm0"
npm run dev
```

The application will run locally on:

```txt id="4jlwmr"
http://localhost:5173
```

# 💡 Application Workflow

```txt id="hjlwm0"
User enters note
        ↓
Form submission handled in AddNote component
        ↓
State updated in App.jsx
        ↓
Updated notes passed to ViewNote component
        ↓
Notes dynamically rendered on screen
```
